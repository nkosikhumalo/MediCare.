## <span style="color: #2d3748;">WHAT IS THIS SYSTEM?</span>

<span style="color: #4a5568;">The RAG system is like a super-smart librarian that reads through all of MediCare's policy documents and finds the exact answers to your questions. It combines powerful search technology with artificial intelligence to give you accurate, helpful responses based on real policy information - not guesses.</span>

---

## <span style="color: #2d3748;">HOW THE SYSTEM WORKS - THE BIG PICTURE</span>

<span style="color: #4a5568;">Think of this system as a smart assistant that follows these steps:</span>

<div style="background-color: #ebf8ff; border-left: 4px solid #4299e1; padding: 15px; margin: 15px 0;">

### <span style="color: #2b6cb0;">STEP 1: LEARNING THE MATERIALS</span>
<span style="color: #4a5568;">When the application starts, the system automatically reads and studies the entire MediCare policy document, breaking it into small, easy-to-search pieces.</span>

</div>

<div style="background-color: #f0fff4; border-left: 4px solid #48bb78; padding: 15px; margin: 15px 0;">

### <span style="color: #276749;">STEP 2: UNDERSTANDING YOUR QUESTION</span>
<span style="color: #4a5568;">When you ask a question, the system figures out exactly what you're looking for and checks if you're allowed to ask that type of question based on your role.</span>

</div>

<div style="background-color: #fffaf0; border-left: 4px solid #ed8936; padding: 15px; margin: 15px 0;">

### <span style="color: #c05621;">STEP 3: FINDING THE RIGHT ANSWERS</span>
<span style="color: #4a5568;">The system searches through all the policy pieces it learned earlier and finds the most relevant sections that answer your question.</span>

</div>

<div style="background-color: #faf5ff; border-left: 4px solid #9f7aea; padding: 15px; margin: 15px 0;">

### <span style="color: #6b46c1;">STEP 4: CREATING A HELPFUL RESPONSE</span>
<span style="color: #4a5568;">Using artificial intelligence, the system writes a clear, friendly answer based only on the policy information it found - never making things up.</span>

</div>

<div style="background-color: #fff5f5; border-left: 4px solid #f56565; padding: 15px; margin: 15px 0;">

### <span style="color: #c53030;">STEP 5: CHECKING FOR SAFETY</span>
<span style="color: #4a5568;">Before showing you the answer, the system double-checks that everything is correct, safe, and follows all the rules.</span>

</div>

## <span style="color: #2d3748;">HOW THE SYSTEM LEARNS - DOCUMENT INGESTION</span>

<div style="background-color: #e6fffa; border: 2px solid #38b2ac; padding: 20px; border-radius: 10px; margin: 20px 0;">

### <span style="color: #234e52;">THE LEARNING PROCESS</span>

<span style="color: #4a5568;">When you start the application, here's what happens automatically:</span>

1. <span style="color: #2c7a7b;">**Read the Document**</span> - The system finds the MediCare policy guide and reads it
2. <span style="color: #2c7a7b;">**Check Version**</span> - It checks if this version has been learned before
3. <span style="color: #2c7a7b;">**Break It Down**</span> - The document gets split into smart, labeled pieces
4. <span style="color: #2c7a7b;">**Create Codes**</span> - Each piece gets a special code that helps with searching
5. <span style="color: #2c7a7b;">**Store Safely**</span> - Everything gets saved in the database for later use
6. <span style="color: #2c7a7b;">**Report Success**</span> - The system tells you if everything worked or if there were problems

</div>

### <span style="color: #2d3748;">THE DOCUMENT BEING LEARNED</span>

<span style="color: #4a5568;">The system learns from the MediCare Technical Guide, which contains:</span>

<div style="background-color: #fffaf0; padding: 15px; border-radius: 8px; margin: 15px 0;">

- <span style="color: #c05621;">Policy structure and basic information</span>
- <span style="color: #c05621;">How premiums work and payment options</span>
- <span style="color: #c05621;">Who's involved (policyholders, beneficiaries, etc.)</span>
- <span style="color: #c05621;">Special features like Immediate Cover and Instant Cash</span>
- <span style="color: #c05621;">How to make changes to a policy</span>
- <span style="color: #c05621;">Claims processes and requirements</span>

</div>

<span style="color: #4a5568;">This document is about 17,920 lines long and contains all the important policy information that users might ask about.</span>

## <span style="color: #2d3748;">SMART CHUNKING - BREAKING DOWN THE DOCUMENT</span>

<div style="background-color: #f7fafc; border: 2px solid #718096; padding: 20px; border-radius: 10px; margin: 20px 0;">

### <span style="color: #2d3748;">HOW CHUNKING WORKS</span>

<span style="color: #4a5568;">The system is smart about how it breaks down the document:</span>

- <span style="color: #4a5568;">**Respects Headings**</span> - It splits at section titles like "Premiums" or "Claims"
- <span style="color: #4a5568;">**Handles Old Format**</span> - Can deal with underline-style headings too
- <span style="color: #4a5568;">**Keeps Right Size**</span> - Each piece is about 1200 characters max
- <span style="color: #4a5568;">**Overlaps Slightly**</span> - Pieces overlap by 150 characters so nothing gets lost
- <span style="color: #4a5568;">**Protects Tables**</span> - Keeps table data together and intact
- <span style="color: #4a5568;">**Labels Everything**</span> - Each piece gets section labels and categories

</div>

### <span style="color: #2d3748;">WHAT EACH CHUNK CONTAINS</span>

<span style="color: #4a5568;">Every piece of the document includes:</span>

<div style="background-color: #edf2f7; padding: 15px; border-radius: 8px; margin: 15px 0;">

- <span style="color: #2d3748;">Section title</span> - Which part of the document it came from
- <span style="color: #2d3748;">Subsection title</span> - More specific location information
- <span style="color: #2d3748;">The actual content</span> - The text itself
- <span style="color: #2d3748;">Type label</span> - Whether it's a table or regular text
- <span style="color: #2d3748;">Category tag</span> - Like "DEATH_CLAIMS" for claims information
- <span style="color: #2d3748;">Effective date</span> - When this information applies
- <span style="color: #2d3748;">Token count</span> - How long the piece is

</div>

## <span style="color: #2d3748;">FINDING ANSWERS - THE SEARCH PROCESS</span>

<div style="background-color: #faf5ff; border: 2px solid #9f7aea; padding: 20px; border-radius: 10px; margin: 20px 0;">

### <span style="color: #6b46c1;">HOW SEARCHING WORKS</span>

<span style="color: #4a5568;">When you ask a question, the system:</span>

1. <span style="color: #553c9a;">**Codes Your Question**</span> - Turns your question into the same type of code as the document pieces
2. <span style="color: #553c9a;">**Compares Everything</span> - Compares your question code against all document piece codes
3. <span style="color: #553c9a;">**Scores Similarity**</span> - Gives each piece a score based on how similar it is to your question
4. <span style="color: #553c9a;">**Filters Results</span> - Only keeps pieces that score above a certain level
5. <span style="color: #553c9a;">**Picks the Best</span> - Selects the top pieces (usually 8) that are most relevant

</div>

### <span style="color: #2d3748;">SPECIAL MODES</span>

#### <span style="color: #6b46c1;">Claims Mode</span>
<span style="color: #4a5568;">When someone has passed away, the system only searches for claims-related information. This prevents beneficiaries from seeing policy details they shouldn't access.</span>

#### <span style="color: #6b46c1;">Mock Mode Search</span>
<span style="color: #4a5568;">In development mode, the system uses keyword matching instead of codes. It's faster but less accurate.</span>

## <span style="color: #2d3748;">CREATING RESPONSES - THE 7-STEP PIPELINE</span>

<div style="background-color: #f0fff4; border: 2px solid #48bb78; padding: 20px; border-radius: 10px; margin: 20px 0;">

### <span style="color: #276749;">THE COMPLETE ANSWER CREATION PROCESS</span>

<span style="color: #4a5568;">Here's exactly what happens from your question to the final answer:</span>

#### <span style="color: #2f855a;">Step 1: Permission Check</span>
<span style="color: #4a5568;">The system first checks if you're allowed to ask this type of question based on your role. Beneficiaries can't ask about policy changes, for example.</span>

#### <span style="color: #2f855a;">Step 2: Find Relevant Information</span>
<span style="color: #4a5568;">The system searches for the most relevant document pieces that answer your question.</span>

#### <span style="color: #2f855a;">Step 3: Build Instructions</span>
<span style="color: #4a5568;">The system creates special instructions for the AI that include empathy, rules, and the found information.</span>

#### <span style="color: #2f855a;">Step 4: Remember Context</span>
<span style="color: #4a5568;">If you've been talking for a while, the system remembers what was said before so you don't have to repeat yourself.</span>

#### <span style="color: #2f855a;">Step 5: Get AI Response</span>
<span style="color: #4a5568;">The system sends everything to an AI service and gets a draft answer. It tries different services if one doesn't work.</span>

#### <span style="color: #2f855a;">Step 6: Safety Check</span>
<span style="color: #4a5568;">The system checks the answer for any problems and fixes them before showing you.</span>

#### <span style="color: #2f855a;">Step 7: Save and Return</span>
<span style="color: #4a5568;">The system saves the conversation for next time and shows you the final, safe answer.</span>

</div>
